# 功过格微信小程序导入与发布

## 工程定位

第一版是原生微信小程序，采用本机存储：

- 不需要后端或云开发；
- 不调用微信登录、手机号、定位、通讯录、相册等接口；
- 不上传功过、善愿或自省内容；
- 卸载小程序、清除缓存或更换设备后，记录可能无法恢复。

## 导入微信开发者工具

1. 登录微信公众平台，创建小程序并取得正式 AppID。
2. 打开项目根目录的 `project.config.json`，将 `appid` 替换为正式 AppID。
3. 在微信开发者工具中选择“导入项目”。
4. 项目目录选择 `gongguo-journal` 根目录，而不是单独选择 `miniprogram`。
5. 编译后检查“今日、功过簿、善愿”三个底部页面。
6. 使用真机预览，重点检查输入法弹起、弹窗滚动、底部安全区和本地保存。

## 发布前验证

- 首次启动没有演示记录。
- 空白功过数量为 0，填写内容后自动变为 1。
- 同一天再次登记会编辑并覆盖当天记录。
- 月历显示每天净数和本月净数。
- 全年视图显示 12 个月净数，点击月份可进入当月。
- 善愿按最新时间排序。
- 满愿卡片默认折叠、不可修改，并显示“圆”徽章。
- 满愿后自动弹出“立下一愿”。
- 过数会从善愿累计中扣除，“距满愿还差”不出现负数。
- 清空本机记录必须二次确认。
- 断网状态下以上功能均可使用。

运行静态检查：

```powershell
node scripts/validate-miniprogram.js
node scripts/test-store.js
```

## 隐私保护指引建议文案

> 功过格仅在当前设备本地保存用户主动填写的功过记录、善愿和自省内容，不将这些信息上传至服务器，不收集微信昵称、头像、手机号、位置、通讯录等个人信息。卸载小程序、清除缓存或更换设备后，本地记录可能无法恢复。

提交审核前，应在微信公众平台根据实际使用的接口重新核对隐私保护指引。如果后续增加登录、云同步、导出、分享或统计服务，需要同步更新隐私说明与授权流程。

## 审核表述建议

推荐将产品描述为：

> 一款本地化的每日自省与行为记录工具，帮助用户记录善行、反思过失，培养持续自律的习惯。

避免使用“保证改命、转运、消灾、预测命运、功德兑换”等承诺性或迷信化表述。第一版也不要加入付费祈福、算命、法事、捐赠或公开社区。
