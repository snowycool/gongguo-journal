# 功过格

依《了凡四训》中袁了凡使用功过格的方法设计：先立善愿，逐日登记，善则记数，恶则退除。项目同时包含网页原型与可导入微信开发者工具的原生小程序源码。

## 已实现

- 当前善愿与累计进度
- 每日晚间登记今日之功、今日之过；空白条目数量为 0，写入内容后自动记为 1
- 功数、过数、净数与累计数自动结算
- 按月日历查看每日净功与本月净数，可切换上月、下月
- 切换全年视图，按12个月查看每月净数
- 多条善愿按立愿时间从新到旧排列，可切换和调整未完成善愿
- 善愿达成后自动标记满愿、授予圆满徽章，并弹出下一善愿表单
- 已满愿卡片默认折叠，展开可查看完整数据，不可再修改
- 参考数字古籍阅读器的清雅界面：暖白纸面、宋体层级、细线分栏与橙色重点标记
- 浏览器本地保存

## 体验

直接使用浏览器打开 `dist/index.html`。原型无需安装依赖。

## 微信小程序源码

- 小程序目录：`miniprogram/`
- 微信开发者工具工程配置：`project.config.json`
- 导入与发布说明：`docs/wechat-release.md`
- 静态校验：`node scripts/validate-miniprogram.js`
- 数据层测试：`node scripts/test-store.js`

正式发布前，请将 `project.config.json` 中的 `appid` 替换为自己的正式微信小程序 AppID。
